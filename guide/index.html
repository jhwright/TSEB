1What this is

TSEB's files used to live in Groups.io and in a dozen volunteers' own Google Drives. The TSEB Library gathers them in one Google Drive folder that belongs to TSEB, sorted the way every circle agreed in September 2026.

For now the library sits in Jeff's Drive. When TSEB's Google Workspace is ready, it moves there in one step. Nothing has been deleted from Groups.io or anyone's Drive.

This page is public. The library is private. Anyone can read this guide, but the library, the FAQ and the comment pages are in Google Drive and require a Google sign-in with access. Their links are marked with a padlock.

Questions? Each section ends with a button that opens that topic's page in a shared Google Doc. Write there; Jeff answers there.

2Adding a file

Drop it in 00 Intake. That's it.

You don't need to choose a folder or rename anything. An AI helper files it in the right circle folder, gives it a date-first name, notes it in the _Intake log, and adds a short summary to meeting notes. Anything it isn't sure about waits in Intake → Needs a decision for Hadas.

Please don't drop

  • Bedside reports or anything about a patient. Send those to the bedside coordinator.
  • Passwords or logins.

Filed in the wrong place? Say so on this section's feedback page. Nothing is ever deleted, so it's easy to fix.

5Sensitive material

Bedside reports may mention patients, and TSEB abides by HIPAA. They are held outside the shared library, in a folder only Jeff can open, until the bedside coordinator decides who may read them. Nobody read them while building the library, and AI tools stay out of them.
  • Every folder inside a shared folder is shared too, so restricted material must sit apart or be set to limited access.
  • Rosters are the member directory: members view, only the roster keeper edits.
  • Passwords don't belong in meeting notes. One old set of minutes has a retired website login that should be blanked out.

6AI in the library

  • Summaries: every set of meeting notes has a short AI summary of topics and decisions, marked with the date. PDFs have a companion Google Doc beside them. The original notes are never changed, so check them when it matters.
  • Filing: AI sorts what's dropped in Intake. It proposes; a person decides anything uncertain.
  • Rules for any AI helper: it acts only as the person using it, links every file its answer relies on, never shares or deletes, labels what it writes, and stays out of bedside reports.
  • Tools: Claude does the bulk filing and summaries. Gemini, built into Google Workspace, is handy for everyday questions.

8Words we use

Intake
The folder where anyone drops new files for filing.
Google Workspace
Google's service for organizations, free for TSEB as a nonprofit.
Shared Drive
Storage owned by TSEB rather than a person, so files stay when people leave.
Shortcut
A pointer to a file placed in a second folder. It doesn't grant access.
Google Group
A named list of people with one email address; folders can be shared with it.
Groups.io
The email-group service TSEB uses, which also had a file area.
AI summary
A short, labelled list of topics and decisions at the top of meeting notes.
Companion doc
A Google Doc beside a PDF, holding its text and an AI summary.
HIPAA
A U.S. law protecting people's health information.
Circle
A group responsible for one area: Leadership (TLC), Communications, Finance, Membership or Music.
