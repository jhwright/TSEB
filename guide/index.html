1What this is

The TSEB Library brings our shared files together in Google Drive. The agreed folder plan follows circles A–I.

Open TSEB Shared Drive, then TSEB Library. TSEB owns this shared file location.

Use Drive directly. Add files to your chosen circle folder.

Most members will read files. Circle contributors can add or change files where their access permits.

2Adding a file

Use these steps when you have permission to add files.

  1. Sign in with your invited Google account.
  2. Open the TSEB Shared Drive, then TSEB Library.
  3. Open the circle folder that fits your file.
  4. For an existing file, choose New → File upload.
  5. For a new document, choose New → Google Docs or New → Google Sheets.

You can use the circle folder itself. A subfolder is optional. Music, recordings, photos, and meeting notes follow the same direct-upload approach.

If the folder or upload option is missing, ask Hadas about access. Keep your original file until you know where to put it.

Names and file formats

Use a clear title. Include the meeting or document date where useful. Start dated file names with year-month-day, using dashes: 2026-10-24 Communications Circle Meeting.

Word documents can become Google Docs, and spreadsheets can become Google Sheets. Keep the original until you check the converted content and formatting.

A file in the wrong folder

Ask Hadas or the circle’s file keeper to correct its location. Keep the file until the correction is complete.

Client information belongs with the bedside coordinators. Keep them out of general circle folders and AI tools.

4Who can see what

Use your own invited Google account. You do not need the administrator’s password or a separate TSEB login for the access Iris provided.

File and folder sharing determine access. Files can inherit access from their folder or Shared Drive.

AreaIntended access
Circle foldersMembers read; designated circle contributors add or edit.
Board minutes and bylawsMembers read; current Board edits.
Rosters and rides informationApproved members read; the file keeper edits.
Confidential client recordsRestricted coordinator handling.

This table describes intended access. Your actual Google Drive permissions determine what you can do. Ask Hadas or Iris if they do not match your role.

Sending someone a link

Use Share → Copy link. For a private file, keep General access: Restricted.

A copied link does not give access. Ask an administrator to add an approved reader who cannot open it.

Before you send material outside TSEB, ask its keeper whether that sharing is permitted.

5Private material and AI help

Client and member information

Brenna and the second bedside coordinator are responsible for confidential client records. Keep those records out of the general library.

Ask the bedside coordinator for the approved restricted location. Workspace administrators can retain administrative access.

Bedside activity reports without confidential client information can be filed in the Music Circle when the coordinator approves. Use the coordinator’s agreed route for confidential client information. If you do not know that route, ask Brenna or Hadas first.

If private material appears in a general folder, do not forward or copy it. Notify Hadas, Brenna, or an administrator.

The authorized owner will correct its access or location and preserve the original record.

Getting help with AI

For AI help, ask about approved, non-sensitive documents or request a summary. Availability and any cost depend on your chosen tool.

Google Drive’s AI features and their cost depend on your account.

Keep confidential client information, passwords, and private member information out of AI tools.

Give an AI helper only the non-sensitive files approved for that task. Ask it to preserve originals and label summaries.

Example request: “Summarize these approved meeting notes. Include clickable links to the original documents so I can check your answer.”

Source links let readers compare an AI answer with the original. AI answers can contain mistakes.

6Using the library together

Agreed

  • The library uses the A–I circle layout.
  • Contributors add files directly to their chosen circle folder. A subfolder is optional.
  • Word documents and spreadsheets can become Google Docs and Sheets after content checks.
  • Labeled summaries and the FAQ remain useful references.

Where to get help

  • Files, folders, or naming: ask Hadas or your circle’s file keeper.
  • Account or access problems: ask Hadas or Iris.
  • Confidential client records: ask Brenna or the bedside coordinator.
  • Guide corrections: use the questions and comments links.

7Words we use

Circle
A group responsible for an area such as Music, Membership, or Finance.
Google Workspace
Google’s service for organizations. TSEB uses it to manage shared work.
Shared Drive
A file location owned by TSEB rather than an individual.
Contributor
A person with permission to add files. This guide uses the word generally; administrators choose the appropriate Drive role.
Shortcut
A link to an original file or folder. It does not change access.
Source link
A clickable link to the original document behind an answer or summary.
