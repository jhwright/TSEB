2Adding a file

Upload it with the Add a file form. That's it.

Use it for ordinary files: minutes, notes, music and photos. No need to pick a folder or rename it. Each night the file is filed, renamed date first and logged. Meeting notes get a short AI summary.

Never upload bedside reports, or anything with client names or patient information. Those go to the bedside coordinator only. No passwords either.

Sign-in: any Google account works, such as your Gmail. For now, uploads go to a private folder only the library owner can open.

Still being decided: form or email to a TSEB address? Hadas and the bedside coordinator will choose the way that best keeps patient information safe. Until then, use the form.

Filed in the wrong place? Say so below. Nothing is deleted, so it's easy to fix.

How intake is processed

A nightly script (or Jeff, on request) does this. It starts in dry-run mode, so you can see what it would do before it moves anything.

Show the processing script
  1. List everything the form has collected (the private upload folder).
  2. For each file, pick the right folder from the folder map. Rename it date first: YYYY.MM.DD Title.
  3. Minutes or notes: add a short AI summary at the top, clearly labelled, listing topics and decisions. Leave the notes unchanged. For a PDF, put a companion Google Doc beside it: summary on top, the PDF's text below.
  4. Add a row to the _Intake log sheet: date, original name, new name, folder, why, and how sure.
  5. Not sure? Move it to Intake / Needs a decision for Hadas.
  6. Looks like a roster, contact list, bedside report, patient or health information, or has a password? Don't open or summarize it. Move it to the private "Held privately" folder (only the owner can open it) and flag it for the bedside coordinator or Jeff.
  7. Never delete, share or overwrite anything. Link every file an answer or summary relies on.

Prompt to paste into an AI helper:

Please process the TSEB Library intake folder. Use only my Google access.

1. List every file in the Add a file form's private upload folder.
2. For each file, choose the right folder in the TSEB Library (A Quick links, B Threshold Leadership Circle, C Communications Circle, D Finance Circle, E Membership Circle, F Music Circle, G Board of Directors, H Archives, I Photos), using the deepest subfolder that fits. Rename it date first: YYYY.MM.DD Title.
3. If it is meeting minutes or notes, add this line at the top: "AI SUMMARY (generated by <tool> on <date>; may contain errors; original notes below, unchanged)". Under it, list the topics discussed and the decisions made. Do not change the original notes. If it is a PDF, make a companion Google Doc beside it with the summary on top and the extracted text below.
4. Add a row to the "_Intake log" sheet: date, original name, new name, folder, why, confidence.
5. If you are unsure where a file goes, move it to "Intake / Needs a decision" for Hadas.
6. If a file's name suggests a roster, contact list, bedside report, patient or health information, or a password, do not open or summarize it. Move it to the private "Held privately" folder outside the library, and flag it for the bedside coordinator or Jeff.
7. Never delete, share or overwrite anything. Link every file your summary or report relies on.

When done, list what you moved, what needs a decision, and what you moved to "Held privately".

5Sensitive material and AI

Bedside reports may mention patients, and TSEB abides by HIPAA. They are held privately, in a folder only Jeff can open, until the bedside coordinator decides who may read them.
  • Google offers its HIPAA agreement to Workspace customers, not personal accounts, so the form and its upload folder move to a TSEB admin account once TSEB's Workspace exists.
  • A folder inside a shared folder is shared too, so restricted files must sit apart.
  • Rosters: members view, only the roster keeper edits.
  • No passwords in meeting notes or the library.

Rules for any AI helper

  • It sees only what the person using it can see.
  • It links every file its answer relies on.
  • It never shares or deletes, and labels what it writes.
  • Nothing sensitive, bedside reports included, goes into AI.

Claude does the filing and summaries. Gemini, built into Google, is handy for everyday questions.

7Words we use

_Intake log
The sheet that records where each Intake file went, and why.
Companion doc
A Google Doc beside a PDF, holding its text and an AI summary.
Circle
A group in charge of one area: Leadership (TLC), Communications, Finance, Membership or Music.
Google Workspace
Google's service for organizations, free for TSEB as a nonprofit.
Shared Drive
Storage owned by TSEB, not a person, so files stay when people leave.
Google Group
A named list of people; folders can be shared with it.
Shortcut
A pointer to a file from a second folder. It doesn't grant access.
HIPAA
A U.S. law protecting health information.
